## 概要

**Onigiri Editor** は、**Tauri v2 + React 19 + TypeScript + Rust** で構築された、macOS・Windows・Linux 対応の軽量・高速な AI 時代向け Markdown / コード / Web 開発プレビュー統合エディタです。

初回起動時は OS の言語設定を自動判定し、**8言語**（**English** / **日本語** / **简体中文** / **繁體中文** / **한국어** / **Español** / **Français** / **Deutsch**）の中から最適な UI とネイティブメニューバーで起動します。

現在のバージョン: `v1.5.5`

## 主な機能

- **3つの UI モード切替（`⌘\` / `Ctrl+\`、直接切替 `⌘⌥1` / `⌘⌥2` / `⌘⌥3`）**:
  - **シンプルモード**: ツールバー・タブ・サイドバーを隠し、拡張子に応じたハイライト付きで書くことだけに集中できる単一ペインモード
  - **標準モード**: エディタ／分割／プレビュー切替、双方向ライブプレビュー、書式バーを備えた標準構成
  - **拡張モード**: マルチタブ（ピン留め・ドラッグ並び替え・デュアルエディタ同時編集＆2タブ差分比較対応）、折りたたみ対応フォルダエクスプローラー（Git 変更バッジ・エディタへの D&D 相対リンク挿入・右クリック操作・画像ギャラリー＆**未使用画像整理**・作業フォルダ解除対応）、**ナレッジタブ（`[[Wikiリンク]]`・バックリンク・`#タグ` ブラウザ＆ナレッジグラフ／リンク切れ診断）**、**Git ソース管理タブ（ステージ/戻す/破棄・Diff 表示・AI コミットメッセージ生成・Pull/Push）**、フォルダー横断正規表現 Grep 一括置換（`⌘⇧G`）、開発サーバー連携、スナップショット、AI ワークスペース連携を備えた高機能構成
  - **ヘッダー非表示時のステータスバー・モード移動**: 上部ヘッダーバーを非表示にしている時は、各モードから 1 クリックで移動できるボタン（`シンプル → 標準` / `標準 → 拡張` / `拡張 → 標準`）をステータスバーに表示します。
- **双方向ビジュアル編集・引用管理・スライド発表・執筆ワークフロー**: 左エディタ（CodeMirror 6）と右ビジュアルプレビュー（TipTap）のリアルタイム同期＆編集中行ハイライトに加え、**スラッシュコマンド（`/`）**、**カスタムスニペット UI**、**目次（TOC）自動生成**、**クリップボード画像の自動保存（`assets/` ＆保存時自動移行）**、**引用・脚注・BibTeX / DOI 検索・リンクカード＆URL タイトル自動取得**、**デイリーノート＆テンプレート**、**URL Web クリップ**、**Markdown スライドプレゼンモード** を搭載しています。
- **100言語以上のシンタックスハイライト・構造化データ・視覚プレビュー**: Markdown・PHP・TypeScript/JavaScript・Python・Rust・SQL・HTML・CSS・YAML・JSON・CSV/TSV・SVG 等に対応し、ステータスバーからの言語切り替え、**CSV/TSV インタラクティブ表プレビュー**、**JSON / YAML / `.env` 整形・変換**、強化された **SVG（ズーム・背景切替・PNG コピー）＆HTML（ビジュアル／ソース切替）プレビュー**、**Mermaid / KaTeX 図表の SVG・PNG 書き出し**、コード折りたたみ、**行ブックマーク永続化（`F2`）**、**フォーカスモード**、`⌘D` 次の一致選択、7種のプリセットと 10 トークン別カラーピッカーを搭載しています。
- **AI チャット（タブ別スレッド）・Apple Foundation Models（Mac 版）・ツールバー AIカスタム＆サブメニュー・ドキュメント校正・適用前 Diff プレビュー**:
  - **Apple Foundation Models（Apple Intelligence オンデバイス、macOS 26+ 限定）** / **Codex CLI** / **Claude Code CLI** / **Gemini CLI** / **Antigravity CLI** / **OpenAI・Anthropic・Gemini API** / **Ollama** / **LM Studio** に対応し、モデル選択・**タブ別／共通チャットスレッド切替**・**会話履歴の `.md` ノート書き出し**・リアルタイム進捗表示と中断ボタン・フォルダ権限ピル・**選択範囲インライン編集（`⌘⇧E`）**・**ツールバー AIカスタムボタン＆長押し／右クリック サブメニュー**（最大 5 件の親ボタン＋各最大 10 件のサブメニューをアイコン・プロンプト・出力チェックボックス・個別ショートカット付きで登録可能、初期プリセット「**AI翻訳**」同梱）・**ドキュメント校正（ルール検査＋AIレビュー）** を備えています。
  - AI による「**本文を置換**」「**選択範囲を編集**」（適用前スナップショット自動保存オプション付き）および「**フォルダーへ書き込み**」の実行前に、行単位の **Diff プレビューモーダル** で変更内容を確認できます。
- **プロジェクト別セッション復元・`.editorconfig` / `.onigiri.json`・ショートカット編集＆JSON バックアップ**: 作業フォルダーごとに開いていたタブ・未保存ドラフト・カーソル＆スクロール位置・折りたたみ状態・ブックマーク・言語固定・最近の履歴・ウィンドウ位置/サイズを保持・復元し、**`.editorconfig` / `.onigiri.json` の自動適用**、**全 112 コマンド＋AIカスタム（親ボタン＆サブメニュー）のショートカットカスタマイズ**（カテゴリ絞り込み・重複警告付き）、**設定・AI・スニペット・テンプレート・キーバインドの JSON バックアップ書き出し／復元**、さらに選択可能な **設定初期化＆キャッシュ削除** に対応しています。
- **外部ファイル変更検知・自動リロード／競合バナー**: 外部ツールや AI CLI によるファイル変更・削除を監視し、未編集タブは自動反映、未保存編集がある場合は **ディスクから再読み込み** / **差分を比較** / **自分の編集を維持** の選択バナーを表示します。
- **開発サーバー診断＆2パターンの Web ブラウザ連携（モノレポ同時起動・ポート指定・AIログ解析・QR／LAN共有対応）**:
  - Vite / Next.js / Astro / Nuxt / Laravel / WordPress / PHP / Django / FastAPI / Flask / Streamlit / Python バックエンド / Hugo / MkDocs / Docker Compose / モノレポ / 静的サイトを自動検出し、**モノレポ内の複数ターゲット同時起動**（例: `gui` と `engine` の並行稼働＆個別停止バッジ）、**対象フォルダー（Target）**・**起動スクリプト（Script）**・**ポート番号（Port）** の指定、および **`> Logs`** による稼働中ログ確認（コピー・クリア・エラー自動ハイライト・**ワンクリック AI 原因解析**）に対応しています。
  - **パターン1（内蔵 Web ブラウザ）**: 右ペインを Tauri マルチ WebView の本格ブラウザへ切替。**ホームボタン**（ホーム URL 設定対応）・**レスポンシブ幅切替（全幅 / タブレット `768px` / モバイル `390px`）**・**★ブックマーク＆履歴バー**・**DevTools（`F12`）**・ショートカット（`⌘L`/`Ctrl+L`, `F5`/`⌘R`, `Alt+←/→`）・サーバー停止時の再起動/ホーム案内バナー付き。
  - **パターン2（外部ライブプレビュー＆プロジェクト LAN 共有）**: ローカル HTTP サーバー（`127.0.0.1` または LAN `0.0.0.0`）でのライブ配信に加え、**プロジェクト開発サーバーの LAN 公開（`LAN: ON / OFF` トグル、`0.0.0.0` バインド自動設定、物理 LAN 優先表示＆`+N 仮想・その他` 折りたたみ、LAN URL コピーチップ＆ QR コード表示）** により同一 Wi-Fi 上のスマホや他 PC からすぐに実機確認できます。
- **その他の便利機能＆自動アップデート管理**: **クイックオープン（`⌘P` / `@見出し`）**、キーボードマクロの記録・再生（`⌘⇧M` / `F8`）、書式ツールバーの編集／拡大縮小ボタン＆ステータスバー表示倍率ポップオーバー（`25%`〜`400%`）、スマート行コピー（`⌘C` / `Ctrl+C`）、Mermaid 図・KaTeX 数式・コールアウト、YAML Frontmatter エディタ、AI 出力整形＆表フォーマット（TSV 表変換貼付対応）、推定 AI トークン数計測、**リッチテキストコピー**＆HTML スマート貼付、検索・置換、コマンドパレット（`⌘K` / `Ctrl+K`）、集中モード（`⌘⇧F` / `Ctrl+Shift+F`）、**自己完結型 Word（`.docx`） / HTML（画像埋め込み対応）** / ソースコード印刷・PDF 書き出し、さらに **アプリ内自動更新＆バックグラウンド定期アップデート確認**（確認間隔設定・自動ダウンロード・リリースノートの新規タブ展開・バージョンスキップ・ワンクリック適用＆再起動）を搭載。
- **初回起動時の OS 言語自動判定（8言語対応）**: **English**・**日本語**・**简体中文**・**繁體中文**・**한국어**・**Español**・**Français**・**Deutsch** の 8 言語に対応し、初回起動時に OS 言語を自動判定します（トップバーのドロップダウンおよび設定画面からいつでも手動切替可能）。

## 動作環境

- **対応 OS**: macOS（Apple Silicon / Intel）、Windows（x64）、Linux（x64）
- **開発・ソースビルド時**:
  - Node.js 20 以上（22 推奨）
  - Rust ツールチェーン（`rustup` stable）
  - Tauri v2 の OS 別依存環境（macOS: Xcode Command Line Tools / Windows: WebView2 + VS C++ Build Tools / Linux: `libwebkit2gtk-4.1-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev` 等）
- **任意（AI / 開発プロジェクト連携時）**: Node.js、Codex / Claude Code / Gemini / Antigravity CLI、Ollama / LM Studio

## ビルド

```bash
# 依存関係のインストール
npm install

# Web プレビュー起動
npm run dev

# デスクトップ開発モード起動
npx tauri dev

# 各 OS 向けリリース用バイナリ / インストーラのビルド
npx tauri build
```

テストおよび型チェックの実行:

```bash
# フロントエンド単体テスト（Vitest）
npm test

# TypeScript 型チェック + 本番フロントエンドビルド
npx tsc --noEmit && npm run build

# Rust バックエンド単体テスト
cargo test --manifest-path "src-tauri/Cargo.toml"
```

## v1.5.5 の更新内容

- **領域別ドラッグ＆ドロップ対応（フォルダツリー / エディタ＆プレビュー / AI チャット）**:
  - **拡張モードのフォルダツリー**: カーソル下のフォルダ行（ファイル上の場合はその親フォルダ）を個別ハイライト表示します。通常ドロップでそのフォルダへ**コピー**、**`Shift` キーを押しながら**離すと**移動**します。
  - **エディタ / プレビュー領域**: 画像ドロップ時はアセットフォルダへ保存してカーソル位置へ挿入します。非画像ファイル（`.md` / `.txt` / `.csv` 等）は通常ドロップで**新しいタブで開き**、**`Shift` または `Ctrl`（Mac は `⌘`）を押しながら**離すと相対パスの Markdown リンク `[ファイル名](パス)` を挿入します。
  - **AI チャット領域（マルチモーダル画像＆ファイル添付）**: テキスト／コード／Markdown 等をドロップすると添付チップとして文脈に追加され、画像をドロップするとサムネイル付きチップとして添付し、Cloud API（OpenAI / Anthropic / Gemini）・Ollama 等には Base64 画像として、CLI プロバイダーには画像パスとして送信します。

## 基本的な使い方

1. **Onigiri Editor** を起動すると、OS の言語設定に応じて日本語または英語で起動します。
2. 上部バーまたは `⌘\` / `Ctrl+\` で **シンプル / 標準 / 拡張** モードをいつでも切り替えられます。
3. Markdown ファイル・ソースコード・ワークスペースフォルダーを開きます（`⌘O` / `Ctrl+O`）。
4. 右上の **パネル／Bot アイコン** から **AI チャット**・**整形ツール**・**統計＆差分**・**Frontmatter**・**設定**（`⌘,` / `Ctrl+,`）を開けます。
5. 右ペインの **内蔵ブラウザ** または **外部ライブプレビュー** を使って、HTML・Markdown・起動中のローカル開発サーバーを並べてプレビューできます。

## ダウンロード

各 OS 向けのビルド済みバイナリは [GitHub Releases](https://github.com/StayHomeLabNet/Onigiri-Editor/releases) ページからダウンロードできます。

- **macOS（Universal: Apple Silicon / Intel 両対応）**: `.dmg` / `.app.tar.gz`
- **Windows（x64）**: `.exe`（NSIS インストーラ） / `.msi`
- **Linux（x64）**: `.AppImage` / `.deb`
